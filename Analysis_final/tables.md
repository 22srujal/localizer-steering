# Final analysis tables

Generated by `Analysis_final/analyze_final.py` from the saved result files only. Each trap file is paired with the clean file from the same folder (`Phase_3` for T1 decoy, T3 pointer, T4; `Phase_3_v2` for the rest). n = 40 tasks unless stated. CIs are 95% Wilson. p-values are exact McNemar (two-sided, doubled binomial tail); every one was checked against an independent exact binomial test in rational arithmetic and against `trap_gen.mcnemar` (all agree to 1e-12). Module-level counts reproduce `summary_p3.txt` exactly.

**Definitions.** *Function level*: the decoy function is among the answer's top 5 functions. *Module level*: the decoy's module (repo parsing, `localizer.module_of_node`) is among the answer's modules; in this data this equals `trap_gen.named_decoy` (function OR module). For T4 the "decoy" is the planted bait function. "up" = named under trap but not clean, "down" = the reverse.
